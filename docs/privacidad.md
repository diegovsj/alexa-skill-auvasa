# Política de privacidad de AUVASA

**Última actualización:** 17 de octubre de 2026

Esta política explica qué datos utiliza la skill de Alexa **AUVASA** (en
adelante, «la skill») y cómo se tratan.

## 1. Responsable

La skill es un proyecto personal e independiente. Para cualquier consulta sobre
privacidad puedes escribir a **diegovsj@hotmail.com**.

## 2. Qué datos se utilizan

La skill **no recopila datos personales** como nombre, correo electrónico,
teléfono o dirección. No solicita permisos de perfil de Alexa ni de ubicación.

La única información que se guarda es la **parada favorita** que el usuario
decide guardar (por ejemplo, «Paseo Zorrilla 198»). Se almacena asociada a un
identificador interno de usuario de Alexa, en la tabla de DynamoDB que Amazon
aprovisiona para las skills *Alexa‑hosted*. El desarrollador **no tiene acceso**
al nombre, correo, teléfono ni a ningún dato que identifique al usuario: solo
podría ver la parada guardada junto a ese identificador interno.

## 3. Para qué se usa

La parada favorita se usa únicamente para responder a preguntas como «¿cuándo
pasa el próximo autobús en mi parada?». No se usa para publicidad, perfilado ni
ninguna otra finalidad.

## 4. Con quién se comparte

No se comparten datos con terceros. El servicio se apoya en la plataforma de
Amazon (Alexa, AWS Lambda y DynamoDB), que trata los datos conforme a sus
propias políticas de privacidad.

## 5. Conservación y supresión

La parada favorita se conserva mientras el usuario la tenga guardada. El usuario
puede cambiarla o borrarla en cualquier momento diciendo «guarda otra parada como
mi parada favorita» o deshabilitando la skill. También puede gestionar sus datos
desde la app de Alexa y la configuración de privacidad de Amazon.

## 6. Menores

La skill no está dirigida a menores de 13 años (o 16, según el país) y no
recopila conscientemente datos de menores.

## 7. Publicidad y compras

La skill no contiene publicidad, no permite compras y no utiliza Alexa Shopping
Actions.

## 8. Cambios

Si esta política cambia, se actualizará esta página con una nueva fecha.

## 9. Contacto

Para ejercer cualquier derecho o resolver dudas: **diegovsj@hotmail.com**.
